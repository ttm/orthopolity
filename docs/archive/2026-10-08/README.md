# Session archive, 8 October 2026

Raw outputs of the two multi-agent investigations run in this session, kept as provenance. The
distilled, maintained versions are [research-program.md](../../research-program.md),
[resource-catalogue.md](../../resource-catalogue.md) and
[configs/resource_catalogue.json](../../../configs/resource_catalogue.json); start from
[status.md](../../status.md).

| File | Contents |
|---|---|
| `research-review-factcheck.json` | Five literature investigations (proportional-growth dynamics, geophysics and astrophysics, ecology, maximum entropy and symmetry, a cross-domain exponent compilation); a paper design with a resource rule, gates, datasets and falsification criteria; a hostile referee report; a citation fact-check |
| `resource-catalogue-workflow.json` | Four domain catalogues of power laws with all proposed resource decompositions, independent checks per domain (including omitted cases), and the cross-domain pattern analysis |

Each claim carries the agent's own verification flag. Web searches were capped and full-text
fetches blocked, so "verified" usually means confirmed from an abstract or search extract.
Edits made when archiving: the incorrect adjective form was normalized to "orthopolic", and paths
to the session scratchpad, where agents kept numerical checks, were replaced by a placeholder;
those scripts were not retained.
