# Next independent prediction: human and language source leads

16 October 2026. Preliminary source audit after the completed biological
assay transfer. **No new human prediction has been qualified or fitted.**
The next step is to establish an independently specified resource or constraint
and a discriminating response before opening numerical participant outcomes.

The earlier [linguistic study](linguistic-resources.md) already transferred a
fitted letter/phoneme cost across genres. Lexical frequencies predicted better,
and physical cost was unidentified. Repeating another word-length regression
would not supply the missing independent input.

## First priority: programmed human foraging

Harhen and Bornstein (2023), *Overharvesting in human patch foraging reflects
rational structure learning and adaptive planning*,
[original article](https://pmc.ncbi.nlm.nih.gov/articles/PMC10068834/),
[DOI 10.1073/pnas.2216524120](https://doi.org/10.1073/pnas.2216524120).
The [author repository](https://github.com/noraharhen/Harhen-Bornstein-2023-Overharvesting-as-Rational-Learning)
is accessible. A successful GitHub tree-metadata request identifies commit
`780c5b117dff0eec2a85d8e9c9473b7eaf7dfc0f`, task code and original participant
CSVs under `experiment/run_exp/data`. CSV bodies were not opened or downloaded.
The README identifies task logic, experiment structure and existing model
comparisons; these are stronger starting inputs than an inferred behavioral
resource price.

Candidate prediction: calibrate a restricted response model in an earlier
task environment and predict residence times or leaving decisions after a
specified change in programmed reward or timing constraints. This is a design
proposal, not a confirmed usable split. First audit the task code and chronology
to establish which quantities are externally assigned and which depend on the
participant's choices. Realized target reward totals cannot serve as independent
budget inputs. The original study already compares marginal-value, temporal-
difference and structure-learning models; a new comparison must include the
relevant established alternatives and explain what the resource account adds.
Learning state, repeated decisions and participant dependence require explicit
treatment. Do not execute source code or decode notebooks' embedded results
as part of a purported predictor-only inspection.

## Speech-duration alternative

Coupé et al. (2019), *Different languages, similar encoding efficiency:
comparable information rates across the human communicative niche*,
[DOI 10.1126/sciadv.aaw2594](https://doi.org/10.1126/sciadv.aaw2594).
The [original repository](https://github.com/keruiduo/SupplMatInfoRate)
and README are accessible. A HEAD request to raw `InfoRateData.csv` returned
HTTP 200 with 96,064 bytes; no CSV body was read. Its schema includes speaker,
language, text, duration, canonical syllable count, entropy and information
density. A separate file describes automatic syllable, pause and phonation
measurements. The README assigns CC BY 4.0 to data and BSD-3 to source code.

This could extend symbolic word costs to measured speech time. Before choosing
a held-out language/speaker split, trace how entropy and density were estimated
and exclude any predictor constructed from target duration. Shared translations,
language relationships and pause conventions matter. This is observational
transfer, not a randomized intervention or an assay of metabolic cost. The
published qualitative finding of comparable information rates is already known.

## Language intervention with unresolved dataset identity

Kanwal et al. (2017),
[DOI 10.1016/j.cognition.2017.05.001](https://doi.org/10.1016/j.cognition.2017.05.001),
is a candidate involving communicative accuracy and production-time pressure.
However, the linked [dataset DOI 10.7488/ds/2536](https://doi.org/10.7488/ds/2536)
has [institutional metadata](https://www.research.ed.ac.uk/en/datasets/data-reported-in-jasmeen-kanwals-phd-thesis-chapter-3/)
describing thesis Chapter 3 contextual-predictability experiments. Resolution
reaches `https://datashare.ed.ac.uk/handle/10283/3312` with HTTP 200, but the
JavaScript landing page did not establish downloadable file identity. Do not
equate these experiments without a source-level match. Time, effort and ambiguity
also need separate operational definitions.

## Exposure and next gate

Access checks above occurred in this session; they are not a frozen local data
archive. Abstracts, qualitative conclusions and some search-result aggregate
statistics were visible. No participant outcome arrays were inspected. Any
later protocol must retain this exposure and pin the acquired sources.

Prioritize the foraging methods audit, keeping speech duration as an alternative.
Specify the resource, independent cost or constraint, reference measure,
calibration/test boundary, rival forecasts and a target-relevant accuracy rule.
The candidate measures are counting over declared participants/conditions or
time; none yet supplies a direct log-orthopolic or linear-orthopolic allocation
test across sizes. Stop before fitting if task constraints cannot generate a
distinct prediction without learning them from the target choices.
